**Duration:** 2026 -- Present
**Advisor:** Dr. Yaohang Li, Old Dominion University & Jefferson Lab

FemtoMind is a DOE Genesis Mission project (Jefferson Lab, Fermilab, Argonne, Stony Brook, William & Mary) building AI infrastructure for QCD science. Built an LLM multi-agent system and an MCP server that let AI agents run multi-step global QCD analyses on HPC clusters end to end: setting up fits, running and monitoring Slurm jobs, recovering failed fits, and analyzing results, with every fit recorded for exact reproduction.

**Keywords:** LLM Agents, Model Context Protocol (MCP), Python, Slurm, HPC
